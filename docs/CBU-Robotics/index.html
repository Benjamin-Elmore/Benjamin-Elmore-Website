Roles

Software Engineer

Since September 2025

I write C++ for the CBU1 VEX U team’s robots. My work has moved from robot control toward the interfaces between sensors, a custom board and the V5 Brain.

Drivetrain and navigation, fall 2025

  • In September and October 2025 I wrote PROS/C++ drivetrain code: a driver-controls module with joystick-driven drive and centralized controller and motor-group configuration.
  • I added a PID function and a baseline point-navigation routine that reads odometry, rotates the target error into the robot frame, and computes proportional x, y and heading commands for the drive motors.
  • I explored Pure Pursuit, including a temporary linear spline search. My spline and odometry work was left unfinished, and I haven’t recorded hardware validation for this code.

ARC sensor firmware, from August 2026

  • I work with electrical and computer engineers on ARC, the C++ firmware for ARSENAL, a custom ESP32-S3 board that connects external sensors to the V5 Brain. The team’s hardware and some existing sensor code are theirs; my part is firmware contributions. See the ARC case study.
  • I prototyped the sensor abstraction, moving from a sensor base class toward configurable setup and read callbacks.
  • I moved I²C communication from Arduino Wire toward the ESP-IDF master API, and added a mutex-protected bus with a noncopyable lock guard so mux channel selection and the sensor transaction stay under one lock.
  • I added optical sensor register reads and writes, position decoding and offset handling, and worked on UART and RS-485 diagnostics.
  • On October 28, 2026 a commit of mine recorded successful RS-485 protocol checks across several packet formats. Optical I²C bring-up and a sensor-to-V5 hardware test are still open.

Tools: C++, PROS, ESP-IDF, FreeRTOS, PlatformIO, ESP32-S3, I²C, UART, RS-485, Git.

Vice President

Since October 2026

I took on the Vice President role in October 2026, alongside my software work. My job is to keep the team’s disciplines moving toward the same goals.

  • I coordinate engineering milestones across the software, electrical and mechanical sides, so work like the ARC firmware and the ARSENAL board lines up.
  • I help plan events and competition preparation for the 2026-27 VEX U season.
  • I check in on members’ progress and look for where I can support their work, because I think leadership means helping others contribute.
  • I wrote a planning framework for the 2026-27 Override season, with Build, Electronics and Software roles and typed task, report and decision formats. It’s a planning document; it contains no robot or field-trial evidence.

Tools: Git and GitHub for review, Markdown planning documents, Node.js for the framework’s validation scripts.
