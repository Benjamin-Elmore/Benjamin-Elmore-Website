02 / Drivetrain control and point-to-point navigation (fall 2025)

Role

Software engineer on CBU1 VEX U. I made 14 commits to the team HamburgerTesting repository between September 16 and October 28, 2025, and 2 commits to a second drivetrain repository. Both repositories include imported PROS scaffolding, which is not my work.

Problem

Drive the robot base from a controller, and move it to a target point using odometry, by issuing left, right and strafe motor commands. Autonomous path following was unfinished.

Approach

  • A driver-controls module and joystick drivetrain control, with the controller and motor groups configured in one header.
  • A PID function, added in one commit.
  • Point navigation using proportional control: it reads odometry, rotates the target error into the robot frame, computes proportional x, y and heading commands, and maps them to left, right and strafe motors. Later commits fixed a target-angle unit issue and a bug in a second spline.
  • An exploration of Pure Pursuit path following with a temporary linear spline search.

Results

Implemented; no on-robot test recorded.

What's next

Spline generation and odometry integration were still open when the focus of the team moved to ARC.
