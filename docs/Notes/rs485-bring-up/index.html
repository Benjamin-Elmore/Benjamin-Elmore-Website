Bringing up a half-duplex RS-485 link on the ESP32-S3

November 10, 2026 · ARC, CBU1 VEX U Robotics

Note

ARC talks to the VEX V5 Brain over half-duplex RS-485: one wire pair, so only one side transmits at a time. The ESP-IDF UART driver has an RS-485 half-duplex mode that drives the direction pin of the transceiver from the UART RTS line, so the firmware does not toggle it by hand.

To test the receiver without the real robot, I wrote a PROS program that sends a 37-byte read request at 115200 baud once per second. When nothing arrived, the first check was the receiver-output wiring of the transceiver to the ESP32 RX pin, ideally with a scope or logic analyzer.

On October 28, 2026 the ESP32-S3 serial monitor showed the request received and parsed: READ header, 22-byte body, sensor ID 1, valid checksum, and both DE AD BE EF frame markers. The capture is on the ARC page.

Scope: that was an isolated bench test of an earlier, read-only protocol. Configuration and reboot packets, and the full pipeline with a real sensor, are not tested on hardware.

Part of the ARC case study. Described at the CPPDev branch, commit 49d54a0.
